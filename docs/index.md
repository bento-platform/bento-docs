# Bento Overview

1. **Bento is a secure web-based application.**
2. It's used to search, upload, store, and organize large datasets in a centralized data warehouse.
3. It's available on two portal platforms:
   - Bento Public
   - Bento Web
4. Designed for:
   - Principal Investigators
   - Researchers
   - Clinicians
   - Technicians

   These users can discover and share genomic data across the C3G research community and bioinformatics networks.

5. Bento can be accessed on any device with a browser.
